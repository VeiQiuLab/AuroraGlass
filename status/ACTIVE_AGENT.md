# Active Agent

No fixed implementation model is authoritative.

Repository state and validated evidence are authoritative. Any implementation
agent — regardless of model or vendor — must obey the repository mainline
documents, the phase gate protocol, and the requirement to back every build /
test / runtime claim with actually executed evidence.

- May change architecture/mainline unilaterally: no
- May advance to the next Phase automatically: no
- Scope authority: none beyond the active Phase
